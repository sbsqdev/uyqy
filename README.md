# Charter Key — чартер и карта Гёчека

Сайт чартерной компании: лодка, город вокруг неё и аккаунт, который превращает поездки
в очки, а очки — в бонусы на следующий чартер.

**Город один — Гёчек** (Турция, залив Фетхие), 12 проверенных мест на карте.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Карта мест** | Стилизованная морская карта (чистый SVG, без внешних тайлов), пины по категориям, поиск, фильтры, карточка места с ценой, часами, советом и чек-ином |
| **Подборки** | Сценарии недели: «штиль — гонку отменили», «ужин после гонки», «рассветный режим», «с командой поддержки», «восстановить спину», «одно большое впечатление» |
| **Регаты** | Три регаты сезона, заявка «я иду» с начислением очков |
| **ИИ-ассистент Charter Key** | Про поездку: лодки и цены по сезону, что входит в чартер, права и радиолицензия, депозит, экипаж, провизия, отмены и переносы, трансфер, очки и приглашения |
| **ИИ-гид по городу** | Про берег: места, цены, часы, в какое время суток куда идти, планы на день, маршруты |
| **Аккаунт** | Регистрация, уровни Юнга → Адмирал, очки, бонусы с промокодами, реферальная ссылка и пороги приглашений |

## Механика аккаунта

Это ядро продукта: без регистрации карта и оба ИИ работают полностью, но очки не копятся
и бонусы забрать нельзя. Попытка чек-ина, заявки на регату или получения бонуса открывает
регистрацию — то есть форма показывается в момент, когда человек уже чего-то хочет.

**Начисления** (`BONUS` в `data.js`):

| Действие | Очки |
|---|---|
| Регистрация | +300 |
| Регистрация по промокоду друга | +150 приглашённому |
| Друг зарегистрировался по вашей ссылке | +250 пригласившему |
| Чек-ин в месте на карте | +30…+90 |
| Заявка на регату | +300…+500 |

**Бонусы за очки** (`REWARDS`): поздний чек-аут (400), провизия на первый день (700),
SUP на неделю (1200), скидка 15% на чартер (2000), сутки чартера в подарок (3500).

**Пороги рефералов** (`REF_TIERS`): 1 друг — SUP на неделю, 3 друга — трансфер из Даламана,
5 друзей — сутки чартера. Ссылка вида `charterkey.app/r/CK-ALINA-5985` генерируется из имени
при регистрации.

```
assets/js/guide.js     ИИ-гид по городу: разбор намерения + ранжирование мест по тегам

assets/js/app.js       состояние, регистрация, очки, профиль, обе вкладки чата

```

## Как добавить место

В `assets/js/data.js`, в массив `points`:

```js
{ id: 'gc-new', cat: 'eat', name: 'Название', x: 42, y: 60,
  price: '€30–50', time: '12:00–23:00', pts: 50,
  desc: 'Одно-два предложения по делу.',
  tip: 'Совет, который знает местный, а не путеводитель.',
  tags: ['рыба','ужин','вечер'] }
```

* `cat` — `eat` / `see` / `do` / `night` / `yacht`
* `x`, `y` — проценты от ширины и высоты карты (0–100)
* `tags` — по ним работают и подборки, и ИИ-гид: пишите их «человеческими» словами

## Живые ИИ вместо офлайн-движков

Сейчас оба ИИ работают локально: разбирают намерение запроса и отвечают из данных —
предсказуемо, без ключей и бэкенда. Чтобы подключить настоящую модель, замените вызов
`engine().answer()` в `assets/js/app.js` на запрос к своему бэкенду:

```js
const res = await fetch('/api/ai', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ query: text, mode, profile: state })
});
```

На сервере — Claude (модель `claude-opus-5`), два разных system-промпта под `mode`:
`assistant` получает правила чартера и баланс аккаунта, `guide` — места города из `data.js`.
Ответ возвращается в формате `{ text, cards, chips }`, который интерфейс уже умеет рисовать.
Ключ API держите на сервере, не в браузере.

## Данные и хранение

Аккаунт, очки, чек-ины, заявки и бонусы лежат в `localStorage` — это демо без сервера.
Кнопка «Сбросить прогресс» в профиле стирает аккаунт.

Контент демонстрационный: названия заведений, цены, условия чартера и количество мест вымышлены.
Город, ориентиры и сезонность — реальные, карта стилизованная, не навигационная.
