# Кильватер — карта регатных городов

Сайт для тех, кто ездит на регаты ради удовольствия. Карта точек в городе, где стоит флот:
что поесть, что увидеть, чем заняться, где починить парус — плюс ИИ-гид, профиль участника,
очки за чек-ины, бонусы и реферальная программа.

**Города в демо:** Гёчек (Турция), Чарвак (Узбекистан), Конаев / Капшагай (Казахстан) — 36 точек.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Карта** | Стилизованная морская карта (чистый SVG, без внешних тайлов), пины по категориям, поиск, фильтры, карточка точки с ценой, часами, советом и чек-ином |
| **Подборки** | Сценарии регатной недели: «штиль — гонку отменили», «ужин после гонки», «рассветный режим», «с командой поддержки», «восстановить спину», «одно большое впечатление» |
| **Регаты** | Календарь сезона, заявка «я иду» с начислением очков, переход к городу на карте |
| **ИИ-гид** | Чат, который отвечает конкретно: место, цена, время, зачем туда. Знает все точки города, календарь и состояние профиля |
| **Профиль** | Уровни (Юнга → Матрос → Шкипер → Капитан → Адмирал), очки, чек-ины, бонусы за очки с промокодами, реферальная ссылка и прогресс 5 приглашений |

## Запуск

Статика без сборки и зависимостей:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно просто открыть `index.html` в браузере.

## Структура

```
index.html            разметка всех секций
assets/css/styles.css дизайн-система: токены, компоненты, адаптив
assets/js/data.js     контент: города, точки, регаты, подборки, бонусы, уровни
assets/js/map.js      отрисовка SVG-карты: вода, суша, изобаты, дистанция гонки
assets/js/guide.js    движок ИИ-гида: разбор намерения + ранжирование точек
assets/js/app.js      состояние, очки, профиль, чат, все обработчики
```

## Как добавить город или точку

Всё правится в `assets/js/data.js`.

**Точка** — объект в массиве `points` нужного города:

```js
{ id: 'gc-new', cat: 'eat', name: 'Название', x: 42, y: 60,
  price: '€30–50', time: '12:00–23:00', pts: 50,
  desc: 'Одно-два предложения по делу.',
  tip: 'Совет, который знает местный, а не путеводитель.',
  tags: ['рыба','ужин','вечер'] }
```

* `cat` — `eat` / `see` / `do` / `night` / `yacht`
* `x`, `y` — проценты от ширины и высоты карты (0–100)
* `pts` — сколько очков даёт чек-ин
* `tags` — по ним работают и подборки, и ИИ-гид, так что пишите их «человеческими» словами

**Город** — объект в `DESTINATIONS`: метаданные, `accent` (цвет карты), `map.land` и `map.islands`
(пути SVG в системе координат `viewBox`), `map.route` — дистанция гонки, `map.labels` — подписи.

## Живой ИИ-гид

Сейчас гид работает офлайн: разбирает намерение запроса и ранжирует точки по тегам —
это даёт предсказуемые ответы без ключей и бэкенда. Чтобы подключить настоящую модель,
замените вызов `Guide.answer()` в `assets/js/app.js` на запрос к вашему бэкенду:

```js
const res = await fetch('/api/guide', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ query: text, city: dest().id, profile: state })
});
```

На сервере — Claude (модель `claude-opus-5`), в system-промпт передаются точки города из
`data.js` и профиль пользователя, ответ возвращается в том же формате `{ text, cards, chips }`,
который уже умеет рисовать интерфейс. Ключ API держите на сервере, не в браузере.

## Данные и хранение

Прогресс (очки, чек-ины, регаты, бонусы, рефералы) хранится в `localStorage` браузера —
это демо без бэкенда. Кнопка «Сбросить прогресс» в профиле очищает состояние.

Контент демонстрационный: названия заведений, цены и количество мест вымышлены.
Географические ориентиры и регатные города — реальные, карта стилизованная, не навигационная.
