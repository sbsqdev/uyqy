# Charter Key — race crew в Гёчеке

Англоязычный сайт под американскую и европейскую аудиторию: места в экипаже гоночной яхты
в Гёчеке (Турция), три тарифа, календарь событий, академия, клубная подписка, карта города
и два ИИ-помощника. Интерфейс и весь контент — на английском.

Продуктовая логика собрана по схеме Хормози: максимум обещанного результата, минимум
усилий со стороны клиента и лестница ценности от бесплатного чек-листа до премиального тарифа.

## Как править контент

Всё в `assets/js/data.js`, кодить не нужно:

* `TIERS` — тарифы: цена, что входит, остаток мест, флаг `featured`
* `REGATTAS` — события: даты, флот, остаток мест, очки за бронь
* `COURSES` — курсы: цена в долларах и в очках, длительность, уровень
* `CLUB` — подписка: цена и список привилегий
* `QUIZ` — вопросы и веса ответов по тарифам (`rail` / `trim` / `helm`)
* `FAQ` — вопрос-ответ, порядок сохраняется
* `DESTINATION.points` — места на карте: координаты в процентах, цена, часы, совет, теги
* `REWARDS`, `REF_TIERS`, `BONUS`, `LEVELS` — экономика очков

Пример места:

```js
{ id: 'gc-new', cat: 'eat', x: 42, y: 60, pts: 50,
  name: 'Name', price: '€30–50', time: '12:00–23:00',
  desc: 'One or two sentences to the point.',
  tip: 'The tip a local would give you.',
  tags: ['fish','dinner','evening'] }
```

`cat` — `eat` / `see` / `do` / `night` / `yacht`. По `tags` работают и подборки, и ИИ-гид.

## Живые ИИ вместо офлайн-движков

Сейчас оба помощника работают локально: разбирают намерение запроса и отвечают из данных —
предсказуемо, без ключей и бэкенда. Чтобы подключить настоящую модель, замените вызов
`engine().answer()` в `assets/js/app.js` на запрос к своему бэкенду:

```js
const res = await fetch('/api/ai', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ query: text, mode, profile: state })
});
```

На сервере — Claude (модель `claude-opus-5`), два system-промпта под `mode`: `assistant`
получает правила тарифов, безопасности и баланс аккаунта, `guide` — места города из `data.js`.
Ответ возвращается в формате `{ text, cards, chips }`, который интерфейс уже умеет рисовать.
Ключ API держите на сервере, не в браузере.

Та же база знаний подходит для Telegram-бота: движки в `guide.js` и `assistant.js` не зависят
от DOM и переносятся в бот без изменений.

## Данные и хранение

Аккаунт, очки, чек-ины, брони, курсы и подписка лежат в `localStorage` — это демо без сервера.
Оплаты имитируются: «Buy $149» и «Join the club» просто открывают доступ и показывают тост.
Кнопка «Reset progress» в аккаунте стирает всё.

Контент демонстрационный: цены, условия, остатки мест и названия заведений вымышлены.
Перед показом реальным клиентам их нужно заменить — в первую очередь условия отмены,
состав тарифов и заявления о безопасности.
